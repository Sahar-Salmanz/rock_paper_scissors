# Rock Paper Scissors Game
![rockpaperscissors_logo](./assets/rock_paper_scissors_banner_title_only.jpg)

## Description
An interactive Rock–Paper–Scissors game where the user plays against a computer-generated opponent.\
Designed to strengthen fundamental programming skills including decision-making logic, randomness, and input validation. \
The project is built around a main class `RockPaperScissor`, which encapsulates the different functionalities.


## Requirements
1. Python 3.10+
